# Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically sync GitHub PRs and Linear issues into todomocop tasks via `todo sync github` / `todo sync linear`.

**Architecture:** Pure reconciliation functions produce `SyncAction` lists from API data + existing tasks. A runner applies each action as an individual DB transaction. New `sync` lib crate sits between `core` and `cli`.

**Tech Stack:** Rust, rust-query 0.8 (schema migration v0→v1), ureq (HTTP), serde_json, clap.

**Spec:** `docs/superpowers/specs/2026-03-25-sync-design.md`

```rust
use rust_query::migration::schema;

#[schema(TodoSchema)]
#[version(0..=1)]
pub mod vN {
    use rust_query::TableRow;

    pub struct Task {
        #[unique]
        pub external_id: i64,
        pub title: String,
        pub description: String,
        pub status: String,
        pub priority: Option<i64>,
        pub workspace: String,
        pub deadline: Option<String>,
        pub snooze_until: Option<String>,
        pub planned_date: Option<String>,
        pub deleted_at: Option<String>,
        pub created_at: String,
        pub updated_at: String,
    }

    pub struct Attachment {
        #[unique]
        pub external_id: i64,
        pub task: TableRow<Task>,
        pub file_name: String,
        pub content_type: String,
        pub data: Vec<u8>,
        pub caption: String,
        pub created_at: String,
    }

    pub struct GithubPrContext {
        pub task: TableRow<Task>,
        #[version(1..)]
        #[unique]
        pub url: String,
        #[version(..1)]
        pub url_v0: String,
        pub repo: String,
        pub number: i64,
        pub state: String,
        #[version(1..)]
        pub title: String,
        #[version(1..)]
        pub author: String,
        #[version(1..)]
        pub reviewers: String,
        #[version(1..)]
        pub review_state: String,
        pub last_refreshed: String,
    }

    pub struct LinearContext {
        pub task: TableRow<Task>,
        pub url: String,
        #[version(1..)]
        #[unique]
        pub identifier: String,
        #[version(..1)]
        pub identifier_v0: String,
        #[version(1..)]
        pub state_type: String,
        pub data: String,
        pub last_refreshed: String,
    }
}

pub use v1::*;
```

**Note:** rust-query requires that when adding `#[unique]` to an existing column, you version-split it: the old non-unique column gets `#[version(..1)]` with a `_v0` suffix, and the new unique one gets `#[version(1..)]`. The migration closure copies the value. If rust-query doesn't require this pattern (i.e. uniqueness can be added/removed without versioning), simplify by just adding `#[unique]` directly. **Test this during implementation — try the simpler approach first.**

- [ ] **Step 2: Update Db::open with migration closure**

In `core/src/lib.rs`, update `open` to call `.migrate()`:

```rust
pub fn open(path: &Path, http: Arc<dyn HttpClient>, config: IntegrationConfig) -> Result<Self> {
    let database = Database::migrator(Config::open(path))
        .ok_or_else(|| anyhow::anyhow!("database version is older than supported"))?
        .migrate(|txn| v0::migrate::TodoSchema {
            task: txn.migrate_ok(|_old| v0::migrate::Task {}),
            attachment: txn.migrate_ok(|_old| v0::migrate::Attachment {}),
            github_pr_context: txn.migrate_ok(|old| v0::migrate::GithubPrContext {
                url: old.url_v0.to_owned(),
                title: String::new(),
                author: String::new(),
                reviewers: "[]".to_owned(),
                review_state: "{}".to_owned(),
            }),
            linear_context: txn.migrate_ok(|old| v0::migrate::LinearContext {
                identifier: old.identifier_v0.to_owned(),
                state_type: String::new(),
            }),
        })
        .finish()
        .ok_or_else(|| anyhow::anyhow!("database version is newer than supported"))?;
    Ok(Db { database, http, config })
}
```

**Note:** The exact migration API may differ — the `v0::migrate::*` types are generated by the `#[schema]` macro. Adjust field names based on what the compiler tells you. The key pattern: provide values for all `#[version(1..)]` columns from old row data or defaults.

```rust
pub(crate) fn load_github_contexts(&self, task_id: TaskId) -> Result<Vec<GithubPrContextData>> {
    let results: Vec<GithubContextSelect> = self.database.transaction(|txn| {
        txn.query(|q| {
            let task = q.join(schema::Task);
            let ctx = q.join(schema::GithubPrContext);
            q.filter(ctx.task.eq(&task));
            q.filter(task.external_id.eq(task_id));
            q.into_vec(GithubContextSelectSelect {
                url: &ctx.url,
                repo: &ctx.repo,
                number: &ctx.number,
                state: &ctx.state,
                title: &ctx.title,
                author: &ctx.author,
                reviewers: &ctx.reviewers,
                review_state: &ctx.review_state,
                last_refreshed: &ctx.last_refreshed,
            })
        })
    });

    Ok(results.into_iter().map(|c| {
        let reviewers: Vec<String> = serde_json::from_str(&c.reviewers).unwrap_or_default();
        let review_state: HashMap<String, String> = serde_json::from_str(&c.review_state).unwrap_or_default();
        GithubPrContextData {
            url: c.url,
            repo: c.repo,
            number: c.number,
            state: c.state,
            title: c.title,
            author: c.author,
            reviewers,
            review_state,
            last_refreshed: c.last_refreshed,
        }
    }).collect())
}
```

```rust
pub fn find_task_by_github_pr(&self, pr_url: &str) -> Result<Option<Task>> {
    let task_id: Option<i64> = self.database.transaction(|txn| {
        txn.query_one(optional(|row| {
            let ctx = row.and(schema::GithubPrContext.url(pr_url.to_owned()));
            let task = row.join(schema::Task);
            row.filter(ctx.task.eq(&task));
            row.then_select(task.external_id)
        }))
    });

    match task_id {
        Some(id) => self.get_task(id),
        None => Ok(None),
    }
}
```

```rust
pub fn reconcile_github(prs: &[GithubPr], existing: &[Task], me: &str) -> Vec<SyncAction> {
    let mut actions = Vec::new();

    // Index existing tasks by their linked PR URLs
    let mut task_by_pr_url: HashMap<&str, &Task> = HashMap::new();
    for task in existing {
        for ctx in &task.github_pr_contexts {
            task_by_pr_url.insert(&ctx.url, task);
        }
    }

    for pr in prs {
        let is_author = pr.author == me;
        let is_reviewer = pr.reviewers.contains(&me.to_string());

        if let Some(task) = task_by_pr_url.get(pr.url.as_str()) {
            // Task exists — check for status changes
            if task.status == TaskStatus::Done || task.status == TaskStatus::Canceled {
                continue; // don't resurrect
            }

            if is_reviewer {
                // Review task: done when review submitted
                let my_review = pr.review_state.get(me);
                if my_review.is_some() && my_review.unwrap() != "pending" {
                    actions.push(SyncAction::MarkDone { task_id: task.id });
                }
            } else if is_author && !task.linear_contexts.is_empty() {
                // Has Linear link → Linear is authoritative, skip GitHub completion
            } else if is_author {
                // No Linear link → check if all non-closed PRs are merged
                let all_prs_for_task: Vec<&GithubPr> = task.github_pr_contexts.iter()
                    .filter_map(|ctx| prs.iter().find(|p| p.url == ctx.url))
                    .collect();

                let non_closed: Vec<&&GithubPr> = all_prs_for_task.iter()
                    .filter(|p| p.state != GithubPrState::Closed)
                    .collect();

                if !non_closed.is_empty() && non_closed.iter().all(|p| p.state == GithubPrState::Merged) {
                    actions.push(SyncAction::MarkDone { task_id: task.id });
                }
            }
        } else {
            // No existing task — create one (but not for already-merged PRs)
            if pr.state == GithubPrState::Merged || pr.state == GithubPrState::Closed {
                continue; // don't create retroactive tasks
            }

            let title = if is_reviewer {
                format!("Review: {}", pr.title)
            } else {
                pr.title.clone()
            };

            actions.push(SyncAction::CreateTaskWithGithub {
                title,
                pr: CreateGithubLink {
                    url: pr.url.clone(),
                    repo: pr.repo.clone(),
                    number: pr.number,
                    title: pr.title.clone(),
                    author: pr.author.clone(),
                    reviewers: pr.reviewers.clone(),
                    review_state: pr.review_state.clone(),
                },
                status: TaskStatus::Ready,
            });
        }
    }

    actions
}
```

```rust
pub fn reconcile_linear(issues: &[LinearIssue], existing: &[Task]) -> Vec<SyncAction> {
    let mut actions = Vec::new();

    // Index issues by identifier
    let issue_by_id: HashMap<&str, &LinearIssue> = issues.iter()
        .map(|i| (i.identifier.as_str(), i))
        .collect();

    // Index existing tasks by their linked Linear identifiers
    let mut task_by_linear_id: HashMap<&str, &Task> = HashMap::new();
    for task in existing {
        for ctx in &task.linear_contexts {
            task_by_linear_id.insert(&ctx.identifier, task);
        }
    }

    // Check for new issues not yet in any task
    for issue in issues {
        if task_by_linear_id.contains_key(issue.identifier.as_str()) {
            continue; // already tracked
        }

        let status = if issue.state_type == "started" {
            TaskStatus::InProgress
        } else {
            TaskStatus::Ready
        };

        actions.push(SyncAction::CreateTaskWithLinear {
            title: issue.title.clone(),
            linear: CreateLinearLink {
                identifier: issue.identifier.clone(),
                url: issue.url.clone(),
                state_type: issue.state_type.clone(),
            },
            status,
            priority: issue.priority,
        });
    }

    // Check existing tasks for state changes
    for task in existing {
        if task.status == TaskStatus::Done || task.status == TaskStatus::Canceled {
            continue; // don't resurrect
        }
        if task.linear_contexts.is_empty() {
            continue;
        }

        // Resolve each linked Linear issue's current state
        let mut all_terminal = true;
        let mut any_completed = false;
        let mut any_active = false;
        let mut all_missing = true;

        for ctx in &task.linear_contexts {
            if let Some(issue) = issue_by_id.get(ctx.identifier.as_str()) {
                all_missing = false;
                match issue.state_type.as_str() {
                    "completed" => { any_completed = true; }
                    "canceled" => { /* terminal but not completed */ }
                    _ => { all_terminal = false; any_active = true; }
                }

                // Status sync: started → in_progress
                if issue.state_type == "started" && task.status != TaskStatus::InProgress {
                    actions.push(SyncAction::UpdateStatus {
                        task_id: task.id,
                        status: TaskStatus::InProgress,
                    });
                }
            } else {
                // Issue no longer in results (unassigned, completed, or canceled)
                // Treat as terminal for simplicity; in the full impl, do targeted lookup
            }
        }

        if all_missing {
            // All linked issues gone → canceled (unassigned)
            actions.push(SyncAction::MarkCanceled { task_id: task.id });
        } else if all_terminal {
            if any_completed {
                actions.push(SyncAction::MarkDone { task_id: task.id });
            } else {
                actions.push(SyncAction::MarkCanceled { task_id: task.id });
            }
        }
    }

    actions
}
```

```rust
use std::collections::HashMap;
use anyhow::{Result, bail};
use todomocop_core::http::HttpClient;
use crate::types::{GithubPr, GithubPrState};

pub struct GithubClient<'a> {
    http: &'a dyn HttpClient,
    token: &'a str,
    user: String,
}

impl<'a> GithubClient<'a> {
    pub fn new(http: &'a dyn HttpClient, token: &'a str) -> Result<Self> {
        // Fetch authenticated user
        let resp = http.get("https://api.github.com/user", &[
            ("Authorization", &format!("Bearer {token}")),
            ("Accept", "application/vnd.github+json"),
            ("User-Agent", "todomocop"),
        ])?;
        let json: serde_json::Value = serde_json::from_slice(&resp)?;
        let user = json["login"].as_str()
            .ok_or_else(|| anyhow::anyhow!("could not get username from /user"))?
            .to_string();
        Ok(Self { http, token, user })
    }

    pub fn username(&self) -> &str { &self.user }

    /// Fetch all open PRs authored by the user + PRs where review is requested.
    /// Also fetches recently merged PRs (within `since_days`).
    pub fn fetch_prs(&self, since_days: u64) -> Result<Vec<GithubPr>> {
        let mut all_prs = Vec::new();

        // Open authored PRs
        let authored = self.search_prs(&format!("type:pr+author:{}+is:open", self.user))?;
        all_prs.extend(authored);

        // Open review-requested PRs
        let reviews = self.search_prs(&format!("type:pr+review-requested:{}+is:open", self.user))?;
        all_prs.extend(reviews);

        // Recently merged authored PRs
        let since = chrono::Utc::now() - chrono::Duration::days(since_days as i64);
        let since_str = since.format("%Y-%m-%d").to_string();
        let merged = self.search_prs(&format!("type:pr+author:{}+is:merged+merged:>={}", self.user, since_str))?;
        all_prs.extend(merged);

        // Dedup by URL
        let mut seen = std::collections::HashSet::new();
        all_prs.retain(|pr| seen.insert(pr.url.clone()));

        // For open review-requested PRs, fetch review status
        for pr in &mut all_prs {
            if pr.reviewers.contains(&self.user) {
                if let Ok(reviews) = self.fetch_reviews(&pr.repo, pr.number) {
                    pr.review_state = reviews;
                }
            }
        }

        Ok(all_prs)
    }

    fn search_prs(&self, query: &str) -> Result<Vec<GithubPr>> {
        let url = format!("https://api.github.com/search/issues?q={query}&per_page=100");
        let resp = self.http.get(&url, &[
            ("Authorization", &format!("Bearer {}", self.token)),
            ("Accept", "application/vnd.github+json"),
            ("User-Agent", "todomocop"),
        ])?;
        let json: serde_json::Value = serde_json::from_slice(&resp)?;
        let items = json["items"].as_array()
            .ok_or_else(|| anyhow::anyhow!("unexpected search response"))?;

        let mut prs = Vec::new();
        for item in items {
            let html_url = item["html_url"].as_str().unwrap_or_default();
            let pr_url = item["pull_request"]["html_url"].as_str().unwrap_or(html_url);

            // Parse repo from URL: https://github.com/{owner}/{repo}/pull/{n}
            let parts: Vec<&str> = pr_url.strip_prefix("https://github.com/")
                .unwrap_or_default().split('/').collect();
            if parts.len() < 4 { continue; }
            let repo = format!("{}/{}", parts[0], parts[1]);
            let number = parts[3].parse::<i64>().unwrap_or_default();

            let state = match (item["state"].as_str(), item["pull_request"]["merged_at"].is_null()) {
                (Some("closed"), false) => GithubPrState::Merged,
                (Some("closed"), true) => GithubPrState::Closed,
                _ => GithubPrState::Open,
            };

            let author = item["user"]["login"].as_str().unwrap_or_default().to_string();
            let reviewers: Vec<String> = item.get("requested_reviewers")
                .and_then(|v| v.as_array())
                .map(|arr| arr.iter().filter_map(|r| r["login"].as_str().map(String::from)).collect())
                .unwrap_or_default();

            prs.push(GithubPr {
                url: pr_url.to_string(),
                repo,
                number,
                title: item["title"].as_str().unwrap_or_default().to_string(),
                state,
                author,
                reviewers,
                review_state: HashMap::new(), // filled in later for review PRs
            });
        }
        Ok(prs)
    }

    fn fetch_reviews(&self, repo: &str, number: i64) -> Result<HashMap<String, String>> {
        let url = format!("https://api.github.com/repos/{repo}/pulls/{number}/reviews");
        let resp = self.http.get(&url, &[
            ("Authorization", &format!("Bearer {}", self.token)),
            ("Accept", "application/vnd.github+json"),
            ("User-Agent", "todomocop"),
        ])?;
        let json: serde_json::Value = serde_json::from_slice(&resp)?;
        let reviews = json.as_array()
            .ok_or_else(|| anyhow::anyhow!("unexpected reviews response"))?;

        let mut state: HashMap<String, String> = HashMap::new();
        for review in reviews {
            let user = review["user"]["login"].as_str().unwrap_or_default().to_string();
            let review_state = review["state"].as_str().unwrap_or("PENDING").to_lowercase();
            // Later reviews override earlier ones
            state.insert(user, review_state);
        }
        Ok(state)
    }
}
```

```rust
            "query": r#"{
                viewer {
                    assignedIssues(
                        filter: { state: { type: { nin: ["triage", "completed", "canceled"] } } }
                        first: 100

                        nodes {
                            id identifier title url
                            state { name type }
                            priority priorityLabel

            "https://api.linear.app/graphql",

                ("Content-Type", "application/json"),

        let nodes = json["data"]["viewer"]["assignedIssues"]["nodes"]

        let mut issues = Vec::new();

                title: node["title"].as_str().unwrap_or_default().to_string(),
                url: node["url"].as_str().unwrap_or_default().to_string(),
```

```rust
use anyhow::Result;
use todomocop_core::Db;
use todomocop_core::types::{AddTask, EditTask};
use crate::types::SyncAction;

/// Summary of what sync did.
#[derive(Debug, Default)]
pub struct SyncSummary {
    pub created: u32,
    pub completed: u32,
    pub canceled: u32,
    pub updated: u32,
    pub errors: Vec<String>,
}

impl std::fmt::Display for SyncSummary {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "Created {}, completed {}, canceled {}, updated {}",
            self.created, self.completed, self.canceled, self.updated)?;
        if !self.errors.is_empty() {
            write!(f, " ({} errors)", self.errors.len())?;
        }
        Ok(())
    }
}

pub fn apply_actions(db: &Db, actions: &[SyncAction]) -> SyncSummary {
    let mut summary = SyncSummary::default();

    for action in actions {
        let result = apply_one(db, action);
        match result {
            Ok(kind) => match kind {
                ActionKind::Created => summary.created += 1,
                ActionKind::Completed => summary.completed += 1,
                ActionKind::Canceled => summary.canceled += 1,
                ActionKind::Updated => summary.updated += 1,
            },
            Err(e) => summary.errors.push(format!("{e:#}")),
        }
    }

    summary
}

enum ActionKind { Created, Completed, Canceled, Updated }

fn apply_one(db: &Db, action: &SyncAction) -> Result<ActionKind> {
    match action {
        SyncAction::CreateTaskWithGithub { title, pr, status } => {
            let task_id = db.add_task(AddTask {
                title: title.clone(),
                description: None,
                status: Some(*status),
                priority: None,
                workspace: "work".into(),
                deadline: None,
                planned_date: None,
            })?;
            // Link the PR using the full method (to be added in Task 3)
            db.link_github_pr(task_id, &pr.url)?;
            // TODO: update the link with author/reviewers/review_state
            Ok(ActionKind::Created)
        }
        SyncAction::CreateTaskWithLinear { title, linear, status, priority } => {
            let task_id = db.add_task(AddTask {
                title: title.clone(),
                description: None,
                status: Some(*status),
                priority: *priority,
                workspace: "work".into(),
                deadline: None,
                planned_date: None,
            })?;
            db.link_linear(task_id, &linear.url)?;
            // TODO: update the link with state_type
            Ok(ActionKind::Created)
        }
        SyncAction::MarkDone { task_id } => {
            db.edit_task(*task_id, EditTask {
                status: Some(todomocop_core::types::TaskStatus::Done),
                ..Default::default()
            })?;
            Ok(ActionKind::Completed)
        }
        SyncAction::MarkCanceled { task_id } => {
            db.edit_task(*task_id, EditTask {
                status: Some(todomocop_core::types::TaskStatus::Canceled),
                ..Default::default()
            })?;
            Ok(ActionKind::Canceled)
        }
        SyncAction::UpdateStatus { task_id, status } => {
            db.edit_task(*task_id, EditTask {
                status: Some(*status),
                ..Default::default()
            })?;
            Ok(ActionKind::Updated)
        }
        SyncAction::UpdateGithubContext { .. } | SyncAction::UpdateLinearContext { .. } => {
            // TODO: implement context update methods in core
            Ok(ActionKind::Updated)
        }
    }
}
```
